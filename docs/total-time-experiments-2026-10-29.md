# 总分结构与时间权重实验（2026-10-29）

> 后续已执行旧模型本赛季诊断、两个影子模型训练及首批赛前留档，见 [当前总分诊断](current-total-diagnosis-2026-10-29.md)。

## 固定实验协议

- 使用已验证缓存 `3cf61fa525ab4784`，3,936 场、213 列、语义版本 9。此阶段不补采数据、不切换生产模型。
- XGBoost 固定原超参数，比较直接总分与固定的“收缩节奏效率基线＋残差”。修正研究入口：显式 `total_strategy=residual` 不因内部验证 MAE 较差而静默切回直接模式；原调用默认 `auto` 保持兼容。
- 伤病特征固定关闭：此前伤病模块对总分尚未通过准入，以无伤病直接 T0 为结构/权重对照。此实验没有重新选择伤病策略，也不改变已获得资格的聚合伤病胜率候选。
- 每种结构比较 T0—T5。窗口与权重在缓存加载后应用，相同样本与权重的候选去重拟合。选择停止点与全过去重拟合均传权重，验证/审计指标不加权。
- 月度固定模型，最近 15% 完整 NBA 比赛日选停止轮数，之后按 `best_iteration+1` 全过去重拟合。开发期 2023-24/2024-25；至少 1,000 条过去样本，因此实际有效开发月份为 2024-04 至 2025-06（休赛期无折）。
- 开发期每种结构以总分 MAE 选择一个时间策略，将开发报告 SHA 和选型写入不可覆盖的锁文件。然后才启动 2025-26 历史审计；审计只报告预先选择的候选，不据其结果重选权重。
- 研究报告包含原始基线的误差、直接与残差的同权重比较、相对直接 T0 的比较、MAE/RMSE/偏差/P90、重要切片和比赛日配对 bootstrap。离线门槛沿用开发改善至少 2%、RMSE 不退化超过 1%、n≥100 切片不退化超过 5%、开发置信区间上界小于零、审计方向一致；前瞻仍另行要求。

## 解释范围

可信缓存仅从 2023-24 开始。开发期 T0、最近两完整赛季＋当季 T1、最近三完整赛季＋当季 T2 的实际样本一致，不能据它们相同的成绩断言古早数据无害或长短窗口没有差别。T3/T4/T5 检验的是当前合格范围内 180/365/730 天半衰期的收益。更早赛季若要纳入公平窗口实验，需要先补齐相同语义的数据质量。

本次只研究 XGBoost 总分；不以这些结果替代 MLP 的独立时间权重实验。所有离线训练仅服务评估，不构建或晋升新的生产包，不启动 200 场前瞻计数。

- `scripts/run_rolling_evaluation.py` 增加明确结构选择、原始基线输出，并将结构、策略列表、超参数写入协议，防止直接/残差报告错误续跑。
- `scripts/summarize_total_experiments.py` 将开发选型与审计汇总分开；锁文件存在时禁止覆盖，汇总核对开发报告 SHA。

- 四个修改/新增 Python 文件语法检查通过。

卷内报告目录 `/app/ml/saved_models/totals_time_v9_20261029/`，本地留存 `reports/totals_time_20261029/`。后续完整结果在本文件末尾补记。

### 固定候选准入

- **直接 T5 不通过**：相对直接 T0，开发改善 0.131%，审计退化 0.553%。
- **残差 T4 不通过**：开发改善 0.554%，MAE 差的比赛日 bootstrap 95% 区间 [-0.234809,+0.053664] 分；审计改善 1.062%，区间 [-0.314112,-0.001233] 分。审计有正向证据，但开发期未达 2% 且区间跨零。
- 两候选 RMSE 均未退化超过 1%，n≥100 切片的最坏退化约 1.47% / 1.45%，没有因切片而失败。不能因其他门槛通过而忽略主要改善门槛。
- 纯节奏效率基线 MAE：开发 15.241149、审计 15.448615，均高于直接 T0；基线作为结构先验的价值不等于它单独比回归模型更准。

### 结构与时间权重分别解释

残差 T4 相对**同权重直接 T4**，开发 MAE 改善 0.580%，区间 [-0.228643,+0.045756]；审计改善 1.998%，区间 [-0.439813,-0.169789]。这是结构对照，不能与相对等权 T0 的 1.062% 混用。

残差 T0 的审计 MAE 已达到 15.197338，时间权重改为 T4 只再降低约 0.00659 分（0.0434%）；开发期降低约 0.04586 分（0.312%）。当前正向信号主要来自结构，尚不支持“更强时间衰减必然更准”。直接模型的 365/730 天权重在审计期均比等权差。

残差 T4 平均偏差从开发的 +0.01666 分变为审计的 +0.53304 分；直接 T0 为 +0.69209 / -0.49298 分。开发偏差接近零并不保证下一季也零偏差。尾部 P90：残差 T4 开发 30.156、审计 32.427，直接 T0 为 29.883、32.092，尾部并未同步改善。

2026-06 最后审计折拟合 3,866 场；等权有效样本量 3,866，730 天约 3,586.87，365 天约 3,000.20。365 天方案中，2023-24／2024-25／2025-26 总权重分别约 530.37／1112.55／2223.08；原始样本数 1237／1313／1316。详细每折截止日、逐季权重、有效样本量均在完整报告中，未把加权验证成绩当作真实成绩。
