## 实际发现与修复

1. 容器 UTC 02:37（北京时间 10:37）的定时任务在 API 进程中自动训练。XGB 拟合完成后因候选目录不可写而失败；该环境也缺少 PyTorch。活动模型没有被替换，但在线请求被同步训练占用。
2. `FeedbackLoop.run_cycle` 现在默认只评估和结算，自动采集回调也遵循此默认。夜间任务明确使用 `evaluate_only=True`，不训练、不更改校准。手动训练入口显式选择训练模式，候选仍须通过晋升门槛。
3. 训练前先探测候选、XGB、MLP 输出目录可写性，不能写时在读取全库／拟合之前失败，并提示使用独立 trainer。未扩大目录权限；独立 trainer 的实际输出探测已通过。
4. 新增完整比赛按 `source_game_date > training_data_until` 统计，而不是 UTC 午夜后的时间戳。修复前检查为 66 场，修复后为 54 场；本轮新补统计后再增加，数字不是永久固定值。截止日当天和缺少已知比赛日的数据不冒充新样本。
5. 手动训练接口现在传递指定赛季，训练失败返回 failed，不能继续显示成“样本不足”；关闭校准时也不误报已更新校准。
