# 决策记录 — 特征工程封顶，停止 Total 特征堆砌

> 日期: 2026-08-13
> 结论: 模型已进入平台期，继续做特征工程不产生边际收益。停止投入，转向产品价值落地。

---

## 结论

**停止一切基于 box score 派生特征的特征工程。** 胜负（win）预测已达可用水平；总分（total）±5 覆盖率卡在 ~20%，且在当前硬约束下已接近天花板，无法通过特征工程突破。

## 依据

最近一次「高级统计回填 + Total 特征 + 指数衰减」重训练 + walk-forward 验证（近 3 赛季 4155 场，initial=200, retrain_every=50, 3955 场预测）：

| 指标 | 之前 | 之后 | 变化 |
|------|------|------|------|
| Win Accuracy | 63.4% | 62.8% | -0.6pp |
| Spread MAE | 11.85 | 11.76 | -0.09 |
| Total MAE | 15.58 | 15.34 | -0.24 |
| Spread ±5 | 27.1% | 27.0% | -0.1pp |
| **Total ±5** | 19.8% | **20.3%** | **+0.5pp** |

全部在噪声范围内，无实质改善。

## 根因

1. **派生高级统计是冗余信息**：pace / off_rtg / def_rtg / ts_pct / efg_pct / tov_pct 都是 pts / fga / fta / tov 等基础 box score 的确定性函数。XGBoost 本就能拟合这些非线性组合，显式喂进去新增信息量 ≈ 0。
2. **无赔率输入是硬约束**：单场总分标准差 ~20 分，只靠 box score 派生特征，±5 命中 ~20% 已接近上限。赔率/盘口是唯一能实质提升 total 精度的信息源，但被项目硬约束禁止。

## 模型当前水平（诚实定位）

- **Win 63%** 已超过 -110 盘口的 ~52.4% 盈亏平衡线，具备真实下注价值。
- **Total ±5 ~20%** 是短板，但无盘口输入下属正常，不应再投入。

## 下一步方向（按优先级）

1. **产品价值落地（推荐）**：把 win 63% 的价值兑现，而非继续追精度 ——
   - 置信度过滤：只向用户推荐 `confidence.level = high` 的场次，用 4 因子评分筛掉噪声场次。
   - 前端只推「高置信度」预测，弱化低置信度场次的展示。
2. **数据覆盖**：保持每日闭环重训练随赛季推进积累数据（记忆已证明数据越多 win 越准，55.6% → 68.5%）。
3. **不推荐**：继续堆派生特征、追 Total ±5 精度、引入赔率（违反硬约束）。
