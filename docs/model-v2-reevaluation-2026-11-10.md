# 按 V2 对当前模型与影子的重评（2026-11-10）

本轮按用户要求采用 `model-admission-v2-proposal-2026-11-10.md` 作为评审口径。V2 删除固定 2% 改善门槛，但保留证据方向、安全性、完整性及 200 场／20 日真实前瞻要求。本轮没有改发布器、重训、修改参数或切换模型；旧研究结论保持原样，新结论是事后重评，不追认成当年已按 V2 预注册。

数据截止：赛果与伤病快照 UTC 2026-11-10 08:03:51（北京时间 16:03:51），数据修订 43091；线上清单与留档在本轮相邻只读采集中核对。逐场结果、锁定来源文件哈希与新评分在 `reports/v2_reevaluation_20261110/`。

因此，本轮早期依据旧摘要说“分差 T4 可过 V2 历史筛查”仅适用于具名的原锁定参考；在同数据版本强对照下，它没有稳定额外优势。两组数值不同源于对照不同，不是旧记录被改写，也不是候选突然退化。新报告同时保留两种对照，不能挑对自己有利的一组当作生产替换证明。

总分 T1 在 1516 场同缓存比较有较弱支持，但扩大为 2631 场后：

二者均未显示总体优势。这是“稳定性证据不足”的实质原因，不能靠取消 2% 自动解决。所有极端赛果保留，没有按赛后大分差删除。

## 2. 实际在线总分影子，7 场、3 日

实际 catalog 是 `totals_213_20261029`。直接影子为 **T5**，残差影子为 **T4**，训练截止均为 2026-10-28；与上面的 T1 是不同规则。两包实际 manifest 与已归档发布候选一致，10 个文件哈希全部核对通过，原工程验证覆盖 125 个输入、单场／批量差为 0。

| 指标 | 同场旧 XGB | 直接影子 T5 | 残差影子 T4 |
| --- | ---: | ---: | ---: |
| MAE | 12.402 | 11.349 | 11.672 |
| RMSE | 14.622 | 12.869 | 13.128 |
| Bias | -0.832 | +1.648 | +2.203 |
| 中位绝对误差 | 11.399 | 12.437 | 13.907 |
| P90 绝对误差 | 21.631 | 16.836 | 17.732 |

这是多指标出现取舍的实际例子：影子平均误差和尾部误差较好，但中位误差和绝对平均偏差没有更好，不能只挑 MAE 宣布全面胜出。

MAE 差异区间：直接 [-3.991,+1.253]，残差 [-4.219,+2.290]。只有三个比赛日，区间仅作描述；均未支持稳定优于生产。绝对 Bias 改善检验也未通过。

其历史原规则开发证据亦不足：直接 T5 开发区间 [-0.09505,+0.05882]，残差 T4 [-0.23481,+0.05366]。直接 T5 的旧审计点估计还恶化约 0.553%；残差 T4 审计改善约 1.062%，但开发不确定性不能被单项较好的审计结果覆盖。V2 的阻塞点已不只是“不到 2%”。

## 3. 胜负影子，4 场、2 日

同场 baseline Brier 0.10703，T5 为 0.09599；log loss 0.38693 →0.34905，二者胜负均 4/4。方向值得保留观察，但有效天数仅 2，不能把很窄的重采样区间或 100% 准确率当作总体保证。

原 2025–26 历史审计 Brier 改善约 0.184%，区间跨零，属于轻微正向但不确定的支持。工程 100 输入单场／批量验证及固定规则折重现已有确切包证据；正式 200 场／20 日仍未满足。

## 4. MLP 修复 A 类评估

| --- | ---: | ---: | --- |
| 胜负 Brier | 0.38228 | 0.20995 | [-0.23034,-0.11322] |

三头均满足 A 类的 1% 非劣预算，且数值上改善明显。但这是**重建安全筛查**，没有通过真实 200 场安全准入。总分绝对 Bias 由 25.518 降为 2.848，差异区间 [-24.676,-20.401]，支持已诊断的数值偏移得到纠正。165 项工程回归、132 条快照重放和原图引擎一致性证据保持完整。

真实手动诊断也不再完全空白：勇士—鹈鹕的一场，保存了两个赛前时间点。两条不是两个独立比赛，本轮固定取更早的 09:42:31 快照作描述，比分由数据库读取为 138–87：

- 旧／修复胜负 Brier：0.77371 →0.07721。
- 原始分差绝对误差：93.086 →43.508；51 分大胜仍计入，没有删除。
- 原始总分绝对误差：31.594 →7.863。

这是一场真实创建的**手动诊断**，不是正式 run，不能算成 200 场。伤病链路未绑定的局限仍存在，不能因为结果改善便跳过功能正确性。

另有 2 场自动成对记录是旧 MLP，不是修复版：旧 MLP 原始总分 MAE 26.832，1 场被 guard 拦截，只有 1 场可展示；XGB MAE 11.256。按原始输出和拦截数一起报告，未只挑未拦截样本。

## 5. V2 共性门槛核对

| 门槛 | 当前结论 |
| --- | --- |
| 纳入记录的赛前时间／哈希／目标训练截止 | 已纳入的真实诊断记录逐条核对；不据此认证未保存的网页预测 |
| 用户伤病→比赛快照→当次输入 | **未通过**：ID35／36 仍未绑定比赛；32798 无对应报告，普通表无该场留档 |
| 原始预处理与行为版本可追溯 | 已保存诊断与修复候选可核对；普通表仅旧预览，平台完整留档链路未满足 |
| ≥100 输入工程验证 | 修复 MLP、总分影子与胜负影子有匹配包的工程支持；不代表真实精度 |
| A 类真实安全非劣 | **证据不足**：修复版只有 1 场手动诊断，没有固定正式队列 |
| B 类开发／最终真实收益 | 按上述具名对照逐项评估；没有模型同时满足全部证据要求 |
| 正式至少 200 场＋20 NBA 日 | **证据不足**：数据库正式 run=0、forecast=0；诊断不能改名充数 |
| 校准概率区间声明 | **证据不足**：没有足量版本一致的真实残差及覆盖率／区间评分证据，不能声称已校准 |

因此，本轮**没有任何候选获得完整 V2 晋升资格**。这并不等于所有优化无效：固定 MLP 修复最值得继续独立真实验证；旧分差／总分候选不再因固定 2% 被一票否决；实际总分影子的开发方向证据和样本量仍不足。

建议接续顺序：先修复已证实的伤病绑定与预测持久化链路并验证漏读为 0；固定 MLP 修复独立真实验证，不等待 XGB 搜索；继续现有影子留档，补足证据。全部步骤保持模型规则冻结，不因中途结果重新搜索参数。

## 复核方法与证据

本轮只重新计算冻结预测的 Brier／MAE／RMSE／Bias／MedAE／P90、原预设切片，以及比赛日配对 bootstrap（4000 次，seed=20261110）。新规则用于事后重评，不能将已反复研究过的开发样本变成全新测试集。

`reports/v2_reevaluation_20261110/` 中：`protocol.json`、`results.json`、`supplement_results.json`（原锁定参考与同缓存参考分别保留）、`absolute_bias_review.json`、真实 payload／协议、当前比分快照、包 manifest、工程报告及哈希核对，足以追踪上述结论。没有重训、重新产生历史赛前预测、改写旧研究结论、混用 T1/T4 或切换模型。
