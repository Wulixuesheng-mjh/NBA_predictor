\# NBA赛事预测平台



\## 项目目标

开发一个Web应用，用于分析中国体育彩票NBA竞猜。用户能选择两支球队，并获得胜负、让分胜负和总得分的预测。



\## 核心功能需求

1\.  \*\*数据采集\*\*：定时拉取NBA赛程、比赛结果、球员数据、伤病名单，以及体彩网的赔率数据。

2\.  \*\*数据分析与预测\*\*：基于球队近期战绩、球员数据、伤病影响和赔率走势，建立预测模型。

3\.  \*\*前端展示\*\*：提供球队选择、数据看板和预测结果展示的可视化界面。



\## 技术栈偏好 (示例)

\*   \*\*后端\*\*: Python (Flask/FastAPI)

\*   \*\*前端\*\*: React + ECharts

\*   \*\*数据库\*\*: PostgreSQL

\*   \*\*数据采集\*\*: `nba\_api` (Python库) + 基于 `requests`/`BeautifulSoup` 的爬虫



## 硬性约束（已确认，不可更改）
- 数据源：仅 nba_api + 手动录入，零爬虫
- 模型：XGBoost（主力）+ MLP（辅助），不使用 Transformer
- 赔率数据：不采集，不作为预测输入
- 回溯窗口：5-15 场可调，赛季初自适应降权
- 预测目标：胜负（分类）、让分（回归）、总分（回归）
